## 🎯 What Each Component Does

### Backend (FastAPI - Port 8000)
```
POST /api/analyze
├─ Accepts: PDF file + job role
├─ Returns: ATS score, skills found, recommendations
└─ Process: Extract → Analyze → Score → Match

GET /api/job-roles
├─ Returns: All 10 job roles
└─ Used by: Frontend dropdown

GET /api/health
├─ Returns: Server status
└─ Used by: Frontend connection check
```

### Frontend (HTML/CSS/JS - Port 8080)
```
User Interface
├─ Upload Section
│  ├─ Drag-drop PDF
│  └─ File validation
├─ Analysis Section
│  ├─ Job role selector
│  └─ Analyze button
└─ Results Section
   ├─ File info
   ├─ ATS score display
   ├─ Skill metrics
   ├─ Charts
   └─ Download report
```

### Shared Modules
```
pdf_extractor.py
├─ extract_text_from_pdf() ........... PyPDF2 extraction
└─ get_pdf_info() .................... Metadata

skill_analyzer.py
├─ extract_skills_from_resume() ..... Find skills
├─ compare_with_job_role() .......... Match skills
└─ get_improvement_suggestions() .... Generate tips

ats_calculator.py
├─ calculate_ats_score() ............ Score calculation
├─ _check_formatting() .............. Formatting check
├─ _check_structure() ............... Structure check
├─ _check_keywords() ................ Keyword analysis
├─ _check_contact_info() ............ Contact check
└─ _check_content_quality() ........ Content quality

job_roles.py
├─ load_job_roles_data() ............ Load from JSON
└─ get_default_job_roles() .......... Fallback data
```

## 🚀 Quick Start (3 Steps)

### Step 1: Install Dependencies (30 seconds)
```bash
pip install -r requirements.txt
```

### Step 2: Start Backend (in Terminal 1)
```bash
python run_backend.py
# or: run_backend.bat (Windows)
# or: ./run_backend.sh (Linux/macOS)
```

Backend running at: `http://localhost:8000`

### Step 3: Start Frontend (in Terminal 2)
```bash
cd frontend
python -m http.server 8080
```

Frontend running at: `http://localhost:8080`

Open browser → `http://localhost:8080` → Start analyzing!
